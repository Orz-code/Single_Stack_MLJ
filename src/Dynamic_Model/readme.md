模型大纲：基于transformer + 自适应稀疏自注意力机制 (ASSA) 的电解槽运行状态时序预测（使用cuda训练）

输入：前120个数据点的电流密度 (Cols.current_density)、小室电压 (Cols.cell_voltage)、碱液温度 (Cols.lye_temp)、出口温度(Cols.temp_out)、碱液流量(Cols.lye_flow)；

输出：后20个点的电压 (Cols.cell_voltage)、出口温度 (Cols.temp_out)

1、原始数据导入：按文件地址读取原始运行数据文件,计算稳态电压值，按时间筛选可用数据

2、数据处理模块：所有数据归一化，保存相应的sclaer；时间滑动窗口切片数据，窗口每次向后移动10个数据点；训练集：验证集：测试集为7：1.5：1.5；最后分为5个batch，每次训练时都依次将所有batch的数据输入进行梯度下降

3、模型模块：编码器正常结构；解码器包含以下ASSA模块 (采用双分支设计（稀疏分支 + 密集分支），在过滤掉无关区域的噪声交互的同时，保留有效的特征信息;同时采用多头注意力进行并行计算，最后通过线性投影来融合多头的结果。)

4、训练模块：训练功能及模型保存功能，在测试集中随机挑选一段90个数据点的输入验证结果
